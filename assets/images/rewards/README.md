# Grafiche dei premi

Metti qui un PNG quadrato per ogni premio, con il nome uguale all'`id` in
`src/domain/rewards.ts`:

```
first-steps.png   tube-pass.png     double-decker.png
big-ben.png       spot-on.png       royal-flush.png
```

Formato consigliato: **512×512 px, PNG con sfondo trasparente**.
Finché i file non ci sono, l'app mostra il segnaposto colorato con l'emoji
(`components/london/reward-badge.tsx`).
